# Enterprise Deposit Reconciliation & Monitoring System (EDRMS)

## Overview

EDRMS is a banking reconciliation and monitoring platform that validates deposit consistency between Core Banking Systems and Enterprise Data Warehouse systems.

The system detects reconciliation failures, displays monitoring status, and notifies responsible users.
